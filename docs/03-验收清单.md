# 03 · 验收清单

改完插件后按这份清单走一遍。能让机器判定的就别靠肉眼。

## 0. 前置

- [ ] Harness 已重启（宿主侧改动才生效）
- [ ] 页面已刷新（客户端半边开始上报主题/焦点）
- [ ] profile 的 `cordis.patch.yml` 里有 `turn-notify` 这一行

## 1. 安装与加载

```bash
# 插件管理里应能看到「对话完成提醒」和它自己的图标
plugin_manager list_plugins
```

- [ ] 状态为启用、无 failed
- [ ] 插件页里的标题、描述、图标正常（中文/英文各看一次）

## 2. 状态通道

```powershell
Invoke-WebRequest http://127.0.0.1:61157/turn-notify/state -Method Get    # 期望 405
Invoke-WebRequest http://127.0.0.1:61157/turn-notify/state -Method Post `
  -Body '{"type":"state","focused":false}' -ContentType 'application/json'  # 期望 204
```

- [ ] GET 返回 405（说明路由被我们的 handler 接管，不是 SPA 兜底）
- [ ] POST 返回 204

## 3. 渲染（绕开截图限制）

```powershell
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass `
  -File notify.ps1 -PayloadB64 <base64> -DumpFrame D:\tmp\frame.png
```

- [ ] 圆角抗锯齿、外投影可见
- [ ] 标题是橘红、正文是主题主文字色、脚注才是灰
- [ ] 正文 1 行 → 卡片约 86px 高；正文 4 行 → 约 136px 高
- [ ] 文字清晰无重影（整数像素绘制）

## 4. 位置与层级

窗口枚举（或目测）：

- [ ] 卡片距工作区右边 **8px**、距任务栏上沿 **8px**
- [ ] 弹出时压在 Harness 之上
- [ ] 弹出后激活 Harness（或打开设置弹窗），卡片仍在最上层（700ms 内抢回）
- [ ] 卡片弹出时**不抢输入焦点**（在别的窗口打字不受影响）

## 5. 交互

- [ ] 悬停：卡片上浮 2px，光标变手型
- [ ] 单击：约 160ms 淡出关闭
- [ ] 不理会：完成卡 8 秒、等待卡 20 秒自动淡出（鼠标停上面也照常计时）

## 6. 触发规则（真实回合）

需要一次 **> 30 秒** 的回合。

- [ ] 切到别的窗口 → 回合结束时弹卡 + 响一声
- [ ] 停在 Harness 且看着这条会话 → **不**弹（精确版不打扰）
- [ ] 中途自己点停止 → **不**弹
- [ ] 子代理的回合 → **不**弹
- [ ] 连续两轮（间隔 < 800ms）只弹最后一次

## 7. 主题跟随

- [ ] 在「个性化」里切深 → 浅，下一张卡片底色/文字跟着变
- [ ] 换第三方主题（如 Everforest）后再弹，颜色是那套主题的
- [ ] 改字号，卡片字号跟着变（卡片宽度不变）

## 8. 声音

- [ ] 完成卡、等待卡都响
- [ ] 两声几乎同时出现时只响一次
- [ ] 系统音量调到 0 时自然静音

## 已知限制（不是 bug）

- 全屏独占的游戏/视频下可能不显示
- 多显示器固定主屏右下角
- 卡片不进通知中心
- 截图工具抓不到卡片（分层窗口），只能用 `-DumpFrame`
